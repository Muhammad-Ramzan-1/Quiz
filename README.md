# Python Quiz App 🧠

A simple command-line quiz program built in Python. The app asks multiple-choice questions, takes user input, checks answers, and shows the final score with percentage.

---

## Features

- Preloaded multiple-choice questions
- Accepts user guesses and checks correctness
- Tracks score and number of correct answers
- Calculates and displays final percentage
- Shows correct answer if the user gets it wrong

---

## How to Run

1. Save the code in a file called `quiz_app.py`
2. Open a terminal and run:

```bash
python quiz_app.py
